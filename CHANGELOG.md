# Changelog

All notable changes to this project will be documented in this file.

## v0.1.0 - 2026-05-27

Initial public research-code release.

Included features:

- Matrix-free scaled HEOM right-hand side for symmetric HTC/Tavis-Cummings models.
- Drude-Lorentz bath coefficient utilities.
- Hierarchy generation and neighbor maps.
- Low-memory classical RK4 propagation.
- Local and SLURM example scripts.
- Documentation for theory, usage, tests, and memory scaling.
- MIT license, citation metadata, and Zenodo metadata.
